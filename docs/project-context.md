# Контекст ToeMath

ToeMath — ранний Docusaurus documentation site. Проверенное содержимое включает tutorial/scaffold материалы, blog posts и один предметный раздел по DC/mesh analysis. Производственная идентичность, домен, навигация и публикационный контракт пока не утверждены; значения `My Site`, `facebook/docusaurus` и example URL в конфигурации являются scaffold, а не требованиями продукта.

Стек: Docusaurus 3.9.2, React 19, TypeScript, Node.js 20+, pnpm lockfile. Проект не содержит backend/API или обязательного automated test runner. Канонические gates — typecheck и static build.
