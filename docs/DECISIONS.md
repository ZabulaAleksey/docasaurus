# Архитектурные решения

## ADR-001 — Docusaurus остаётся текущей платформой

Статус: принято для существующего baseline. Миграция не меняет стек без продуктового требования.

## ADR-002 — pnpm lockfile является каноническим

Статус: заменено миграцией 2026-08-24. Используется `pnpm@11.23.0` и `pnpm install --frozen-lockfile`; единственный lock-файл — `pnpm-lock.yaml`. Общий content store и global virtual store уменьшают дублирование, а возврат к npm/yarn требует отдельного решения и полного regression-прогона.

## ADR-003 — Scaffold metadata не считается production contract

Статус: принято. Название, domain/baseUrl, organization/project links, locales и edit links утверждаются отдельным этапом до deploy.

## ADR-004 — Один execution-state owner внутри Docusaurus repository

Статус: принято после read-only reconciliation 2026-09-15.
`docusaurus.config.ts` и `docs/project-context.md` подтверждают, что
product identity ещё не утверждена; выбран `TOEMATH-PRODUCT-IDENTITY`
со статусом `blocked`. Прежние AI-файлы были историческим источником
governance/dependency evidence и сохранены в `docs/notes` с source hashes.
Текущий state владеет только `docs/STAGES.md`.

Каталог `docs/` является также Docusaurus content directory с
autogenerated sidebar. Docs-plugin `exclude` для корневых governance files
и `notes/**` не позволяет публиковать внутренний execution state и migration
evidence. Product `intro.md`/tutorial routes не меняются; scaffold metadata
и product decision остаются отдельным Stage 1 blocker.
